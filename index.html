Slate & Teal Design System

A compact, systematic style guide for web interfaces — design tokens, a consistent component set, and clear interactive states, hand-built in semantic HTML and CSS.

About this system

This system gives a product one visual language: a restrained slate foundation, a single teal accent family, a 4-point spacing scale, and components that behave the same way everywhere they appear. Every value on this page comes from a CSS custom property (a design token), so changing a token updates the whole system at once — the same discipline used when building a component library in Sketch or Webflow, expressed here directly in code.

Principles: consistency over decoration, contrast-safe color pairings, visible focus states, and components documented with their states — not just their happiest appearance.

Color palette

Slate carries structure and text; teal is reserved for interactive elements and emphasis. Click any swatch to copy its hex code.

Slate scale

Teal accent family

Contrast note: body text uses Slate 900 on white / Slate 50, muted text uses Slate 600, and primary buttons pair white text with Teal 700 — each pairing clears WCAG AA for its text size.

Typography

A single system sans stack, sized on a clear scale. Headings use tight leading; body copy uses relaxed leading for readability.

Body · 1rem / 16px, line-height 1.6

Body copy is set at 16px so interfaces stay readable at arm's length and on small screens. Short paragraphs, plain language, and consistent spacing do more for clarity than decoration ever will.

Caption · 0.75rem / 12px, Slate 600

Captions label figures, timestamps, and supporting metadata. Captions never carry essential information on their own.
